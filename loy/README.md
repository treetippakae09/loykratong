# 🪷 บางขุนเทียน ลอยใจไปกับสายน้ำ
เกมจำลองชีวิตในงานลอยกระทง 3 มิติ สำหรับนักเรียนโรงเรียนพิทยาลงกรณ์พิทยาคม
แนวคิด: **ลอยสิ่งที่หนักใจ และส่งสิ่งดี ๆ ให้กัน** — ไม่มีการจัดอันดับนักเรียน กระทง หรือข้อความ

## เทคโนโลยีโดยสรุป
| ส่วน | เทคโนโลยี |
|---|---|
| หน้าเว็บ | HTML + JavaScript (ES Modules) ไม่ต้อง build — วางบน GitHub Pages ได้ทันที |
| 3 มิติ | Three.js r160 (โหลดจาก CDN jsdelivr) โมเดล Low-poly สร้างด้วยโค้ดทั้งหมด |
| ข้อมูลส่วนตัว / ร่างกระทง | localStorage ของเบราว์เซอร์ (รีเฟรชแล้วไม่หาย) |
| แม่น้ำส่วนรวม + ผู้ดูแล | Google Apps Script ตัวเดียวกับระบบประกวด (`../Code.gs`) + ชีต `LOY_Floats` — ถ้าเซิร์ฟเวอร์ยังไม่ Deploy เวอร์ชันใหม่จะใช้ **โหมดสาธิตชั่วคราว** |

## โครงสร้างไฟล์
```
loy/

├─ logo.png          ตราโรงเรียน
└─ js/
   ├─ data.js        ครู 24 คน บทสนทนา กิจกรรม พื้นที่ ข้อมูลป่าชายเลน
   ├─ krathong.js    วัสดุ 21 ชนิด ฐาน 3 แบบ แบบสำเร็จรูป 5 แบบ · ข้อมูลชิ้นงาน → โมเดล 3 มิติ
   ├─ avatar.js      ตัวละคร Low-poly + แอนิเมชัน เดิน/ยืน/ทักทาย/ก้มวาง/ถือ
   ├─ world.js       โลกงานวัด ตารางเดิน A* ครู NPC แม่น้ำ ฉากชวนครูเดินไปท่าน้ำ
   ├─ workshop.js    โต๊ะประดิษฐ์กระทง 3 มิติ
   ├─ viewer.js      บ่อทดลอง / ดูกระทงระยะใกล้ / ตัวอย่างตัวละคร
   ├─ store.js       บันทึกข้อมูล (ในเครื่อง / โหมดสาธิต / Apps Script) + คัดกรองข้อความ
   ├─ audio.js       เสียงบรรยากาศสังเคราะห์ (น้ำ จิ้งหรีด เสียงดนตรีเบา ๆ)
   └─ main.js        ควบคุมเส้นทางหลักและหน้าจอทั้งหมด
```

## ติดตั้งและตั้งค่า
### 1) ทดลองเล่น (โหมดสาธิต)
ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (ES Modules เปิดจากไฟล์ตรง ๆ ไม่ได้) เช่น
```bash
cd ~/Desktop/loy && python3 -m http.server 8080
```
แล้วเปิด http://localhost:8080 — ในโหมดนี้แม่น้ำส่วนรวมเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น

### 2) ฝากเว็บบน GitHub Pages
อัปโหลดทั้งโฟลเดอร์ (`index.html`, `config.js`, `logo.png`, โฟลเดอร์ `js/`) → Settings › Pages › Deploy from a branch (main / root)

### 3) เชื่อมแม่น้ำส่วนรวม (รวมกับระบบประกวดแล้ว)
เกมนี้อยู่ในโฟลเดอร์ `loy/` ของระบบประกวด และใช้ `Code.gs` ไฟล์เดียวกับระบบประกวด (อยู่โฟลเดอร์ด้านบน)
1. เปิด Apps Script ของระบบประกวด → วาง `Code.gs` ใหม่ทั้งไฟล์ → บันทึก → Run `setup` หนึ่งครั้ง
2. Deploy › Manage deployments › ✏️ Edit › Version: **New version** › Deploy (URL `/exec` เดิมใช้ต่อได้)
3. `config.js` ใส่ URL เดียวกับระบบประกวดไว้แล้ว ไม่ต้องแก้

### ผู้ดูแลระบบ
⚙️ ตั้งค่า › 🛡️ ผู้ดูแลระบบ (หรือเปิด URL ต่อท้าย `#admin`) · ค่าเริ่มต้น `admin` / `1234`
- โหมดออนไลน์: ตรวจสิทธิ์ที่ฝั่งเซิร์ฟเวอร์ (Apps Script) ทุกคำสั่ง
- ภาพรวม · ตรวจข้อความที่ถูกคัดกรอง/รายงาน · แสดง/ซ่อน/ลบ · ตั้งวันเปิด–ปิดงานและระยะเวลาเก็บข้อมูล · เปิด/ปิดวัสดุและแบบกระทง · แก้ชื่อ รูปลักษณ์ บทสนทนาครู (JSON) · ล้างข้อมูลเมื่อสิ้นสุดกิจกรรม

## ฟังก์ชันที่ทำงานแล้ว (ทดสอบเส้นทางหลักครบวงจร)
- **เข้าใช้งาน**: ชื่อเล่น + ชั้นเรียน + สร้างตัวละคร (ทรงผม 6 แบบ สีผม สีผิว ชุด 4 แบบ ท่อนล่าง 4 แบบ สีเสื้อ/ท่อนล่าง/รองเท้า เครื่องประดับ 6 แบบ) พร้อมตัวอย่าง 3 มิติ เลือกได้อิสระไม่จำกัดตามเพศ · เปลี่ยนชุดภายหลังที่ซุ้มแต่งตัว แล้วตัวละครในเกมเปลี่ยนจริง
- **แผนที่ 10 พื้นที่** เดินถึงกันได้: ทางเข้า ซุ้มแต่งตัว ลานงานวัด ซุ้มครู 24 ซุ้ม ศาลาประดิษฐ์ ศาลาพักใจ บ่อทดลอง ท่าน้ำ สะพานป่าชายเลน สายน้ำแห่งความทรงจำ + ซุ้มไอศกรีมริมเล เวที ซุ้มอาหาร อุโบสถ เรือ ปลาตีน ปูก้ามดาบ ดอกเกลือ หิ่งห้อย ไฟประดับ
- **การเดิน**: คลิก/แตะเพื่อเดิน (หาทาง A* หลบร้าน ต้นไม้ น้ำ) · WASD/ลูกศร · จอยสติ๊กเสมือนบนมือถือ · ปุ่มโต้ตอบเมื่อเข้าใกล้ · แผนที่ย่อ (แตะเพื่อเดิน) · ปุ่มนำทาง · กล้องติดตามนุ่มนวล ไม่หมุน
- **ครู NPC 24 คน** ตามรายชื่อ แต่ละคนมีบททักทาย 2 แบบ เกร็ดความรู้ 3 เรื่อง กิจกรรม 1 กิจกรรม คำแนะนำทำกระทง คำแนะนำข้อความ บทตอบรับเมื่อถูกชวน และข้อความส่งท้าย · มีป้าย "ตัวละครจำลอง ไม่ใช่คำพูดของครูจริง"
- **ครูสมจริงตามคำนำหน้าชื่อ**: นาง/นางสาว = ผู้หญิง (สรีระผู้หญิง ผมยาว/มวย/บ๊อบ กระโปรง/ผ้านุ่ง ชุดไทยมีสไบ) · นาย/Mr. = ผู้ชาย (ไหล่กว้าง ผมสั้น เสื้อเชิ้ต/ชุดพื้นเมือง กางเกง) · ทุกคนมีป้ายชื่อห้อยคอสีประจำกลุ่มสาระ · ผู้ดูแลแก้รูปลักษณ์ได้
- **ครูเดินอยู่ทั่วงาน ไม่ประจำซุ้ม**: เดินแวะยืนตามจุดต่าง ๆ (ลานวัด เวที ศาลา ท่าน้ำ สะพาน ฯลฯ) หยุดและหันมาทักเมื่อนักเรียนเข้าใกล้ · ดูตำแหน่งครูเป็นจุดสีบนแผนที่ย่อ · ปุ่มนำทาง/แตะที่ครูจะเดินตามหาครูให้อัตโนมัติ · ซุ้มกลุ่มสาระยังคงเป็นฉากตกแต่ง · หลังคาซุ้มและต้นไม้ที่บังตัวละครจะจางลง
- **ศาลาประดิษฐ์**: แบบสำเร็จรูป 5 แบบ (โอบใจ เริ่มใหม่ ขอบคุณ ริมเล ความหวัง) ปรับสี/ชนิดดอกไม้/ของตกแต่ง หรือนำเข้าโต๊ะ 3 มิติ · ประดิษฐ์เองจากฐานเปล่า 3 แบบ · ร่างของฉัน (แก้ไข ใช้ ทำสำเนา ลบ)
- **ดอกไม้สมจริง**: กลีบแต่ละกลีบโค้ง ห่อ ปลายแหลม ไล่สีจากโคนถึงปลาย — ดาวเรืองกลีบหยักซ้อนเป็นพุ่มกลมพร้อมกลีบเลี้ยงสีเขียว · ดอกบัวกลีบใหญ่ 3 ชั้นพร้อมฝักเมล็ดและเกสร · กล้วยไม้มีกลีบเลี้ยง กลีบดอก และกลีบปากสีเข้ม · บานไม่รู้โรยเป็นช่อกลมรีมีใบประดับเรียงเกลียว พร้อมก้านและใบ · กลีบโรยโค้งงอนธรรมชาติ (รวมกลีบเป็นโมเดลเดียวต่อดอกเพื่อให้ลื่นไหล)
- **โต๊ะประดิษฐ์ 3 มิติ**: ถาดวัสดุ 6 หมวด · แตะวัสดุแล้วแตะบนฐานเพื่อวาง · ลากย้าย · หมุน เอียง ปรับขนาด ปรับความสูง · ทำสำเนา ลบ เปลี่ยนสี · เลือกหลายชิ้นย้ายเป็นกลุ่ม · ย้อนกลับ/ทำซ้ำ · จัดกึ่งกลาง · วางชิดพื้นผิวอัตโนมัติ · เตือนชิ้นนอกฐาน/ลอยค้างโดยไม่ลบ · **เรียงรอบฐาน** (4–16 กลีบ ระยะ มุมเอียง มุมเริ่ม ดูตัวอย่างก่อนยืนยัน แสดง 360° ÷ n) · มุมกล้องบน/หน้า/เฉียง/รีเซ็ต · โหมดหมุนกล้อง/ย้ายวัสดุแยกกัน · เส้นขอบเฉพาะชิ้นที่เลือก · เพดาน 80 ชิ้น · ปุ่มลัด Delete, Ctrl+Z/Y/D · บนมือถือเป็นถาดเปิด–ปิด
- **บ่อทดลอง**: กระทงจากข้อมูลชิ้นงานเดียวกัน ลอย แกว่ง เงาสะท้อน หมุนดูรอบด้าน · คำแนะนำจากครูตามบทบาท (สมดุล สี จำนวนชิ้น วัสดุ) · ระบุชัดว่าเป็นการจำลองเพื่อการเรียนรู้ ไม่ปิดกั้นการร่วมกิจกรรม
- **ข้อมูลชิ้นงาน** (schema 1): ฐาน สีฐาน รายการวัสดุ+รหัสชิ้น ตำแหน่ง การหมุน ขนาด สี รุ่น ภาพตัวอย่าง เจ้าของ เวลาแก้ไข — ใช้ชุดเดียวกันตั้งแต่โต๊ะประดิษฐ์ → บ่อทดลอง → ถือเดิน → วางลงน้ำ → ลอยในแม่น้ำ (ทดสอบแล้วว่าตรงกันทุกชิ้น) · เมื่อลอยจะบันทึกสำเนา ณ ตอนนั้น
- **ข้อความ 3 ส่วน** (ถึงแม่น้ำ / ถึงเพื่อน / ถึงตัวเอง-ไม่บังคับ) ช่องละ 200 ตัวอักษร มีตัวนับ ประโยคช่วยเริ่ม ตัวอย่างก่อนยืนยัน · เลือกแสดงชื่อ 3 แบบ · "ถึงตัวเอง" เห็นเฉพาะเจ้าของ
- **ชวนครู**: ครูตอบรับเฉพาะตัว → ถ้ายังไม่มีกระทงแนะนำไปประดิษฐ์ → ถือกระทงที่ออกแบบ (ใหญ่ใช้ถาดรอง) → เดินเคียงกันไปท่าน้ำ กล้องตามทั้งสอง → ตรวจข้อความ/ชื่อ → ก้มวาง → กระทงชิ้นเดิมสัมผัสน้ำ เกิดวงน้ำ ลอยออกไป → ครูให้กำลังใจ โบกมือ แล้วเดินเที่ยวงานต่อ → เลือกเที่ยวต่อหรือติดตามกระทง · ข้ามฉาก/ยกเลิกได้ · กดยืนยันซ้ำไม่สร้างกระทงซ้ำ · ครูตัวจริงที่เดินอยู่ในงานเป็นผู้ร่วมเดิน (เพราะครูไม่ประจำซุ้มแล้ว)
- **แม่น้ำต่อเนื่อง**: ตำแหน่งคำนวณจากเวลาปล่อย (ไม่ต้องเปิดเครื่องค้างไว้) · แตะกระทงเพื่ออ่านข้อความและดูโมเดล 3 มิติ · ตามหากระทงของฉัน · ติดตามกระทง · แสดงเฉพาะกระทงใกล้กล้อง (สูงสุด 40) + ลดรายละเอียดเมื่ออยู่ไกล · ปฏิกิริยา 3 แบบเป็นแสงชั่วคราว ไม่มีคะแนน · เจ้าของแก้ข้อความ/ถอนกระทงได้ · สายน้ำแห่งความทรงจำ
- **กิจกรรมเสริม** (ไม่บังคับ): เก็บขยะกับน้องปลาตีน · สำรวจป่าชายเลน 5 จุด · จัดกลีบให้สมมาตร · วางดอกไม้ให้สมดุล · คำนวณต้นทุน (ราคาจำลอง) · พูดชวนเพื่อนเป็นภาษาอังกฤษ · แต่งกลอนสองบรรทัด (ใส่ลงข้อความได้) · ข้อความขอบคุณ · ไอศกรีมริมเล
- **ความปลอดภัยของข้อความ**: คัดกรองเบอร์โทร อีเมล ลิงก์/บัญชีโซเชียล คำไม่สุภาพ → รอผู้ดูแลตรวจ · รายงานข้อความ (ครบ 3 ครั้งซ่อนรอตรวจ) · จำกัดการลอยถี่ (20 วินาที) · ตรวจข้อมูลชิ้นงานฝั่งเซิร์ฟเวอร์ · ไม่มีแชตเสรี · ไม่ใช้ AI วิเคราะห์ข้อความนักเรียน
- **ไม่แสดงชื่อ**: ข้อมูลสาธารณะไม่มีชื่อ ชั้น หรือรหัสเจ้าของ (เซิร์ฟเวอร์เก็บเพียงค่าแฮชของโทเคน) · ระบุว่า "ไม่แสดงชื่อแก่ผู้ร่วมงาน" และผู้ดูแลยังตรวจสอบเจ้าของได้
- **การเข้าถึง**: โหมดคุณภาพต่ำ/กลาง/สูง · ปิดเงาสะท้อน · ลดภาพเคลื่อนไหว · เปิด–ปิดเสียง · ข้ามฉาก · ปุ่มสัมผัสขนาด ≥ 44px · โหมดสำรองแบบสำเร็จรูปเมื่ออุปกรณ์ไม่รองรับ 3 มิติ

## ส่วนที่ยังเป็นการจำลอง / ต้องตั้งค่าเพิ่ม
- **ยังไม่มีระบบผู้เล่นหลายคนแบบเรียลไทม์** — ไม่เห็นตัวละครของผู้เล่นคนอื่นเดินในฉาก (เกมแจ้งไว้ที่มุมจอ) สิ่งที่แชร์ร่วมกันคือ "แม่น้ำส่วนรวม" ผ่าน Apps Script ซึ่งอัปเดตทุก 20 วินาที
- ยังไม่ได้ทดสอบผู้ใช้พร้อมกัน 40 คน — Apps Script มีโควตาและใช้ LockService ทีละคำขอ ควรทดสอบจริงก่อนวันงาน หากช้าอาจต้องย้ายไปฐานข้อมูลอื่น (เช่น Firebase)
- ยังไม่ได้ Deploy `Code.gs` (รวม) เวอร์ชันใหม่ — ปัจจุบันเกมขึ้นป้าย "โหมดสาธิตชั่วคราว" (ทดสอบโค้ดฝั่งเซิร์ฟเวอร์กับ Google Sheet จำลองแล้ว ผ่านทั้งระบบประกวดและงานออนไลน์)

## อัปเดต: วิชาการออกแบบและเทคโนโลยี + คำอธิษฐาน (พ.ย. 2569)
- **ตัวละครคงตามที่เลือก** (เพิ่มตัวเลือกรูปร่าง ชาย/หญิง/มาตรฐาน · เปลี่ยนชุดแล้วสีเสื้อที่เลือกเองไม่ถูกรีเซ็ต)
- **ถือกระทงตลอด**: ออกแบบเสร็จหรือกด "ใช้ & ถือ" ตัวละครจะถือกระทงเดินไปท่าน้ำ (รีเฟรชแล้วยังถืออยู่) จนกว่าจะลอย
- **คำอธิษฐาน**: พิมพ์ตอนลอย (≤ 60 ตัวอักษร) แสดงบนป้ายใบตองของกระทง ทุกคนมองเห็นในแม่น้ำ · ผ่านการคัดกรองข้อความเหมือนข้อความอื่น
- **ไม่มีแบบสำเร็จรูปแล้ว** มีแท็บ 💡 แรงบันดาลใจ (ดูภาพได้อย่างเดียว)
- **ชิ้นส่วนใหม่**: ดอกไม้ (กุหลาบ เบญจมาศ ดอกรัก บัวตูม มาลัยมะลิ) ยอดพุ่ม ไม้กลัด ขนมปัง เชือกกาบกล้วย โบใบตอง
- **กลไก**: เพลา เฟือง (กำหนดจำนวนฟัน) รอก+สายพานอัตโนมัติ ใบพัดกังหัน — แสดงอัตราทดและรอบ/นาที
- **ไฟฟ้า/เซ็นเซอร์**: รางถ่าน โซลาร์เซลล์ สวิตช์ ตัวต้านทาน LED มอเตอร์ LDR เซ็นเซอร์น้ำ เซ็นเซอร์เอียง — ต่อสายอัตโนมัติ ตรวจวงจรทีละขั้น (V = IR, P = VI, IPO)
- **⚖️ จุดศูนย์ถ่วง**: จุดแดงบนกระทง + แผนภาพมุมบน + สูตร x̄ = Σ(m·x) ÷ Σm
- **📐 คณิต**: พิมพ์องศาหมุน/เอียงได้ ปุ่ม ±15°/±45° แปลงองศา↔เรเดียน เรียงรอบฐานแสดง 360° ÷ n
- **✂️ โต๊ะช่าง**: เลือกเครื่องมือ (กรรไกร คัตเตอร์ ไม้บรรทัด แม่แบบ ฯลฯ พร้อมความปลอดภัย) ลากตัดตามเส้น → กลีบพิเศษเก็บใน 🧺 วัตถุดิบของฉัน
- **✏️ วาดชิ้นส่วน**: วาดเส้น → สร้างเป็นดอกไม้ / แผ่นตัดตามรูป / ทรงกลึง เลือกสีได้
- **📸 บันทึกภาพ** (PNG 1080×1350) ลงคอมหรือมือถือ (แชร์/บันทึกลงอัลบั้ม หรือกดค้างที่ภาพ)
- **มือถือแนวตั้ง**: แถบเครื่องมือย่อเป็นไอคอน ถาดวัสดุ/แผงปรับแต่งเป็นแผ่นเลื่อนจากด้านล่าง หน้าต่างย่อยเต็มจอ
- ⚠ ต้อง **Deploy `Code.gs` ใหม่** (Manage deployments → Edit → New version) ไม่เช่นนั้นเซิร์ฟเวอร์จะตัดชิ้นส่วนใหม่และคำอธิษฐานทิ้ง
